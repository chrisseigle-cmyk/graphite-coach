# Graphite Coach

Turn a portrait photo into a pencil study, then draw it yourself with a fixed seven-step plan.

Live site: https://chrisseigle-cmyk.github.io/graphite-coach/

Everything runs in the browser: the photo never leaves your device, and there is no server, login or tracking.

## How it's built

A single file, `index.html`, holds the page, its styles and its JavaScript. GitHub Pages serves it straight from the `main` branch, so any change pushed to `main` goes live a minute or two later.
